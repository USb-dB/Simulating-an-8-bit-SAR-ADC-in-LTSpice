# 8-bit CMOS SAR ADC Design and Simulation

This project presents the transistor-level design and simulation of an **8-bit Successive Approximation Register (SAR) ADC** using **50-nm CMOS technology** in LTspice. The ADC is built hierarchically using CMOS logic, sample-and-hold, comparator, SAR logic, R-2R DAC, output register, and clock-generation blocks. The complete ADC was assembled and verified through transient simulation, demonstrating the conversion of an analog input into an 8-bit digital output.
